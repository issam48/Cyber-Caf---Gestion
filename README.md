# نظام إدارة مقهى الإنترنت

تطبيق مكتبي محلي يعمل على Windows باستخدام Electron وReact وTypeScript وSQLite. واجهة الاستخدام عربية باتجاه RTL، وقوالب المستندات المطبوعة بالفرنسية. لا يتصل التطبيق بخدمة سحابية.

## التشغيل

يتطلب Node.js وnpm. من مجلد المشروع:

```powershell
npm.cmd install
npm.cmd run dev
```

إنشاء نسخة تثبيت Windows:

```powershell
npm.cmd run package
```

التحقق:

```powershell
npm.cmd test
npm.cmd run typecheck
```

## البيانات والنسخ الاحتياطي

قاعدة البيانات والصور محفوظة في مجلد بيانات المستخدم الدائم الخاص بـ Electron على Windows، وليس في مجلد تثبيت التطبيق. ينشئ التطبيق نسخة يومية تلقائية ويحتفظ بآخر 14 نسخة يومية. ومن قسم «النسخ الاحتياطي» يمكن أيضاً إنشاء نسخة في مجلد تختاره، أو استعادة مجلد نسخة سابق بعد التحقق من قاعدة البيانات والمرفقات.

## الإصدار والضرائب

لا تُطلب بيانات المحل عند بدء الاستخدام. يلزم إدخال اسم المحل والعنوان والهاتف قبل إصدار مستند رسمي. تحفظ كل وثيقة لقطات بيانات المحل والعميل والضريبة وقت إنشائها. TVA معطلة افتراضياً، ولا تُطبق نسبة تلقائية ما لم يحددها المالك. تُحجز أرقام المستندات عند الإصدار فقط، مع تسلسل مستقل حسب النوع والسنة. يدعم الأرشيف البحث والتصفية حسب النوع والعميل والحالة والتاريخ والمبلغ، ويعرض الروابط بين الفواتير الأولية والفواتير والإيصالات والإشعارات الدائنة.

## ملاحظات

يتضمن التطبيق قسماً لإدارة ملفات Word (DOC/DOCX) وPDF وExcel (XLS/XLSX): رفع الملفات، تسميتها وإعادة تسميتها، توزيعها على تصنيفات قابلة للإنشاء والترتيب، ثم حفظ نسخة منها إلى مجلد يختاره المستخدم. النقر المزدوج يفتح الملف في التطبيق الافتراضي المرتبط به؛ وتُفتح ملفات PDF عبر معالج روابط الملفات في المتصفح الافتراضي. تُحفظ الملفات في مجلد البيانات المحلي وتدخل ضمن النسخ الاحتياطية. تُنقل بيانات ملفات Word المرفوعة في الإصدارات السابقة تلقائياً إلى جدول الملفات الجديد وتُسند إلى تصنيف «غير مصنف».

تتضمن الواجهة أيضاً صفحة «الدخل اليومي» لإدخال المبلغ في بداية اليوم ونهايته وحساب الفرق تلقائياً. يُحفظ سجل مستقل لكل تاريخ ويمكن مراجعته أو تحديثه لاحقاً.

يمكن تصدير المستندات بصيغتي PDF وWord DOCX من نافذة تفاصيل المستند، مع تضمين معلومات المحل والعميل والبنود والضرائب والإجماليات، ودعم النصوص العربية وصور الشعار والتوقيع.

تتضمن النماذج والمخرجات البنية العملية الأساسية لإدارة المحل والعملاء والفواتير الأولية والعروض والطلبات والإيصالات والإشعارات الدائنة، وسجل التغييرات والطباعة والتصدير PDF. يجب على مالك النشاط مراجعة الحقول والمتطلبات القانونية المحلية قبل استخدام المستندات كوثائق رسمية؛ التطبيق لا يقدم استشارة ضريبية أو قانونية.
